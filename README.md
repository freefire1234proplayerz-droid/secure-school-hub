# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/freefire1234proplayerz-droid/secure-school-hub.git
```

Flutter

```bash
flutter pub get

flutter run
```

Backend

```bash
cd server

npm install

cp .env.example .env

npm start
```

Seed Demo Data

```bash
npm run seed
```
